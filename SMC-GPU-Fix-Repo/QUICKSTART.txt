SMC GPU Fix - Quick Start Guide
================================================================

WHAT IS THIS?
-------------
Performance fixes for Super Mecha Champions that improve GPU
compatibility and reduce stuttering on modern phones.

BENEFITS
--------
✓ 71% fewer CPU-skinning stalls
✓ Support for 42+ modern GPUs
✓ Smoother gameplay on mid/high-end devices

REQUIREMENTS
------------
• Windows PC with ADB installed
• Android phone with USB debugging enabled
• SMC installed (com.netease.g93na)

INSTALLATION (30 seconds)
--------------------------
1. Connect your phone to PC via USB
2. Open PowerShell in this folder
3. Run: .\Manage-GPU-Fixes.ps1 -GpuSkinPatch
4. Start the game

That's it! The fixes are now active.

CHECK IF IT WORKED
------------------
After playing a match, run:
  .\Manage-GPU-Fixes.ps1 -PullLog

Then check the log file for "does not support GpuSkin" lines.
You should see ~35 instead of ~122.

REMOVE IF NEEDED
----------------
If you have any issues:
  .\Manage-GPU-Fixes.ps1 -Remove

TROUBLESHOOTING
---------------
Q: "ADB not recognized"
A: Install platform-tools from developer.android.com

Q: "No device found"
A: Enable USB debugging in Developer Options on your phone

Q: "Fixes don't seem to work"
A: Make sure you restart the game after installing

Q: "Game crashes after install"
A: Run the remove command above and report the issue
