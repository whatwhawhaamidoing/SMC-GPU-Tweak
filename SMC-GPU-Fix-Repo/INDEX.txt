HOW TO USE THIS REPO
--------------------

For End Users:
  1. Read QUICKSTART.txt
  2. Run Manage-GPU-Fixes.ps1 -GpuSkinPatch
  3. Play the game

For Developers/Contributors:
  1. Read README.md for technical details
  2. Check COMPATIBILITY.md for testing info
  3. Review CHANGELOG.md for iteration history

For Distribution:
  • Share the entire SMC-GPU-Fix-Repo folder
  • Or zip it for easier distribution
  • Keep all files together for proper functionality

================================================================

VERSION CONTROL
---------------
This repo is designed to be updated as:
• New GPU families are released
• Game updates change requirements
• Better patching strategies are discovered
• Community reports issues on specific devices

Each update should increment the version in CHANGELOG.md
